# 音频素材接口（可选）

游戏默认使用**程序合成音效 + 浏览器 TTS 声线**，无需任何素材文件即可运行。  
如果你有自己的音频文件，放进对应位置即可**自动覆盖**合成音，无需改代码。

## 1. 通用音效（放在 `assets/audio/` 目录）

| 文件名         | 触发时机       |
| ----------- | ---------- |
| `jump.mp3`  | 起跳 / 二段跳   |
| `coin.mp3`  | 吃金币、顶出金币   |
| `stomp.mp3` | 踩敌人、顶碎砖块   |
| `hurt.mp3`  | 受伤         |
| `power.mp3` | 吃到无敌星      |
| `oneup.mp3` | 吃到爱心（加命）   |
| `clear.mp3` | 过关         |
| `die.mp3`   | 死亡         |
| `skill.mp3` | 释放角色技能     |
| `bgm.mp3`   | 背景音乐（循环播放） |

## 2. 角色语音（放在 `assets/audio/voice/` 目录）

命名规则：`{角色id}_{场景}.mp3`

- 角色 id：`shin`（小新）、`kazama`（风间）、`nene`（妮妮）、`masao`（正男）、`boo`（阿呆）
- 场景：`select` 选中、`jump` 跳跃、`hurt` 受伤、`coin` 吃金币、`skill` 放技能、`clear` 过关、`die` 死亡

示例：`voice/shin_skill.mp3`、`voice/nene_clear.mp3`

角色语音文件**不存在**时，自动使用浏览器语音合成（每个角色预置了不同的音高/语速，形成不同声线），同时以字幕气泡显示台词。

## 说明

- 文件格式建议 mp3 / ogg / wav，浏览器能播放即可。
- 自动探测在「点击角色卡片」和「开始关卡」时触发；文件存在才启用，探测失败静默回退，不影响游戏。
- 通过标题页的「音效 / 背景音乐 / 角色声线」开关可以随时关闭对应声音。
